# Background essays

These essays were lightly edited for v0.5 (wording only); the original versions are in the git history.

The documents in this folder are background essays written while the tools in this
repository were being developed. They describe the motivation and informal reasoning
behind ideas such as external memory, quiet periods and handoff packages. They are
not part of the tool's specification, API or security model, and nothing in them is
required to install, configure or use the software; the normative documentation lives
in the top-level `README.md` and the files it links.
